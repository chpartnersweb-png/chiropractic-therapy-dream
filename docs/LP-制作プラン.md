# カイロセラピードリーム LP制作プラン

作成日：2026年11月4日。計画後の追加依頼により、サイト実装とヒーロー画像・ロゴ生成を実施済み。ユーザー指定により、実装後の確認（ビルド・テスト・ブラウザ表示）は行っていない。公開は未実施。編集方法は`docs/EDITING.md`を参照。

## 1. 制作の軸

**一人ひとりの身体に合わせた、あなただけの施術。**

身体の左右差への気づきから始まり、選べる施術と料金、院長の人柄、サロンへの行き方を知り、電話で相談できるLPにする。見た目は参考サイトの白・ブラウン・ゴールド・ローズを継承する。院長の支給写真と14の施術メニューを中心に、地域のサロンとしての親しみと落ち着きをつくる。

- 主な導線：メニュー・料金を確認 → 院長を知る → 電話で予約・相談。
- 写真、見出し、細い罫線、余白で構成。セクションごとに写真の大きさと情報密度を変える。
- ヒーローは1枚の生成画像を画面全体に配置し、コピーは2行。左右分割は使わない。
- 未提供の施術時間、割引、人気順位、口コミ、資格、予約制度、駐車場は追加しない。
- 一般的な依頼区分に「鍼灸」とあるが、支給メニューには鍼灸施術がないため、提供サービスとして追加しない。

## 3. デザイン仕様

### 配色

### 文字と余白

- 日本語見出し：Shippori Mincho。本文・料金・営業時間：Noto Sans JP。
- 英語補助見出し：Cormorant Garamond。日本語を主情報にする。
- 本文16〜18px、行間1.8〜2.0。料金の桁と「円」を読みやすく揃える。
- PC本文最大幅は約1120〜1200px。セクション間余白は100〜150pxを基準とする。
- スマートフォンの左右余白20〜24px。セクション間余白64〜88px。
- 大きな角丸、強い影、装飾的なアイコンの反復を避け、長方形の写真と紙面のような組み方で整える。

### 生成ロゴ

- 「D」を連想させるゆるやかな曲線と、左右のバランスを表す2本の線を組み合わせたシンボルを生成する。

- 日本語の正式名称は生成画像の文字に頼らず、整えた文字組みで「カイロセラピードリーム」と正確に添える。
- 濃いブラウン版、白抜き版、ファビコン用のシンボルを用意。背景透過。
- これはWeb用に新しく制作するロゴ。外観写真の既存看板は支給写真のまま扱う。

## 6. GSAP・Lenisのアニメーション計画

演出の目的は写真と文字への視線誘導。テキストはHTMLとして初期表示可能な状態を基本にする。

| 箇所 | 動き | 目安 |
| --- | --- | --- |
| ヒーロー | 写真を1.03倍から等倍へ、コピーは行単位でフェード | 約0.8〜1.2秒。ローディング待ちは入れない |
| 身体への問いかけ | 見出しが12〜16pxほど上がりながら現れる | 約0.6〜0.8秒、一度のみ |
| 細い装飾線 | スクロールに合わせて線が静かに伸びる | 区間を短く限定 |
| メニュー | 章見出し、写真、料金表の順で出現 | 約0.08秒の小さな時間差。1行ずつ長く待たせない |
| 院長紹介 | 写真と見出しをゆっくりフェード | 約0.8秒 |
| 施術室 | PCのみ写真の位置を小さく変える | 最大15〜24px程度。タッチ操作では省略 |
| ボタン | 色と矢印を小さく変化 | 約0.2秒、focus時も分かる表現 |

- GSAP ScrollTriggerでセクション出現を管理。
- LenisはPCのホイール操作に穏やかな慣性を付ける。GSAP tickerと更新ループをまとめて同期する。
- タッチ操作は端末本来のスクロールを基本とする。
- `prefers-reduced-motion: reduce`では慣性・パララックス・出現移動を停止し、全内容を表示する。
- 長時間のスクロール固定、横移動で読む料金表、追従カーソル、文字単位の長い演出は入れない。
- アンカー移動後の位置とフォーカスを整え、固定ヘッダーが見出しを隠さないようにする。

静的な本文はAstroコンポーネントで出力。価格・電話・営業時間は共通データから参照し、各導線での表記ずれを防ぐ。画像はAstroの画像機能で適切な大きさへ最適化し、ヒーローを優先読み込み、下部画像は遅延読み込みにする。

SEOは院名・地域・支給サービスに基づくtitle、description、OGP、見出し構造を用意。公開ドメインが確定してからcanonical・サイトマップを設定。構造化データは事業実態を確認し、確定した所在地・電話・受付時間に基づく適切な事業種別を選ぶ。

## 8. 実施順序・確認

1. 生成ヒーローとロゴシンボルを制作し、実写真と並べて色・画質・雰囲気を合わせる。
2. 画面全体の余白と写真比率を決め、PC・モバイルの静的レイアウトを実装。
3. 14のメニューと支給経歴、電話導線を反映。
4. GSAP・Lenisを実装し、タッチ操作・動きを減らす設定で調整。
5. 住所・価格の税区分などを確定させ、アクセスとSEO情報を整える。
6. ビルド、実表示、キーボード操作、電話番号、地図、表示幅320〜1440pxを確認する。

開発サーバーが必要な場合はAGENTS.mdに従い`astro dev --background`で起動し、`astro dev status`、`astro dev logs`、`astro dev stop`で管理する。
