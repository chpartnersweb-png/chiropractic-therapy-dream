# 編集ガイド

## 事業情報

`src/data/site.ts` に電話番号・受付時間・定休日・地図リンクなどを集約しています。電話番号を変更する場合は表示用の `phone` と発信用の `phoneHref` を両方変更してください。

正式住所はユーザー確認済みの「〒207-0013 東京都東大和市向原6丁目949-21」です。`area` に東京都東大和市、`streetAddress` に向原6丁目949-21を設定しています。住所変更時は両項目と `mapEmbed` の検索指定を更新してください。本文と構造化データは同じ住所データを参照しています。

## メニュー

`src/data/menu.ts` に14メニューを掲載しています。料金は数値で設定し、ページ側で3桁区切りにしています。税区分は支給されていないため税込・税別の表記を追加していません。施術時間、駐車場、支払い方法、予約制の有無も未提供のため記載していません。

## 画像

`src/data/images.ts` で素材を割り当てています。支給写真は `src/assets/images/`、新しく生成したヒーローとロゴは `src/assets/generated/` です。

画像はAstroのImageコンポーネントで出力します。ファーストビューは優先読み込み、それ以外は遅延読み込みです。写真内の情報を書き換えず、表示範囲はCSSと画像変換の寸法で調整しています。

外観の看板には今回指定と異なる電話番号が写っています。本文・電話リンクは090-4814-4345へ統一し、外観写真は入口を中心に表示しています。

## 色・文字・レイアウト

`src/styles/global.css` の冒頭に色とフォントの変数があります。白・ブラウン・ゴールド・ローズを基本とし、760px以下をスマートフォン用レイアウトにしています。ヘッダーの切り替えは900pxです。

## 動きと操作

`src/scripts/motion.ts` にGSAP・ScrollTrigger・Lenis、モバイルナビゲーション、アンカー移動をまとめています。

- LenisはPCかつ精密なポインターがある場合に使用。
- タッチ操作は標準スクロール。
- 動きを減らす設定ではGSAPの出現・パララックスとLenisを停止。
- JavaScriptなしでも本文・メニュー・料金・電話・地図リンクが表示される構成。
- モバイルナビゲーションはdialogを使い、Escapeで閉じられる構成。

## 公開ドメイン

正式URLは `https://chiropractic-therapy-dream.pages.dev/` です。`src/config/seo.mjs` にURL・タイトル・説明をまとめてあります。公開URLを変更する場合は同ファイルの `siteUrl` を更新してください。Astroのsite設定、canonical、OGP、構造化データ、robots.txt、サイトマップが参照します。詳しい設定と再デプロイ後の運用は `docs/SEO.md` を参照してください。

## 今回の実施範囲

LPのソース実装、画像・ロゴ生成、素材の組み込み、編集資料を作成し、その後の依頼で画像設定・数字のフォント・SEO設定を更新しました。SEO対応では変更前の公開ページのメタ情報を読み取っています。ユーザー指定に従い、実装後のビルド、テスト、開発サーバー起動、ブラウザ表示確認は実施していません。こちらからのデプロイも実施していません。

開発サーバーを起動する際はAGENTS.mdに従い `astro dev --background` を使用してください。管理は `astro dev status`、`astro dev logs`、`astro dev stop` です。
